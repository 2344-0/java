# 斗破苍穹 · 网页包

斗气大陆登录 / 注册 / 首页 三页联动演示包。

## 文件清单
- `斗破苍穹登录页.html` —— 主入口，萧炎手执异火 + 玄重尺主题登录页
- `斗破苍穹注册页.html` —— 立契注册页（账号 / 秘钥 / 手机号 / 咒印校验）
- `斗破苍穹首页.html` —— 登录后跳转的异火图鉴首页（含导航栏 + 搜索栏）

## 如何打开
直接用浏览器打开 **`斗破苍穹登录页.html`** 即可（双击文件，或拖入浏览器窗口）。
三页之间的跳转依赖相对路径，请保持本文件夹内三个文件在一起，不要单独移走某一个。

## 页面流转
```
登录页  ──"立下契约，成为斗者"──►  注册页
  ▲                                      │
  │                                      │ 注册成功（"契约已立"）
  │                                      ▼
  └──────"返回登录"（注册页底部）─────────┘
  │
  └── 登录成功 ──►  首页（斗破苍穹首页.html）
```

## 说明
- 本包为**纯静态前端演示**：登录 / 注册的成功跳转均为前端模拟，未接入后端数据库。
- 若需接入真实后端（Spring Boot + MySQL 注册 / 登录接口），可参考同机 `Desktop/springBootTest` 与 `Desktop/java-main` 工程进行联调。
